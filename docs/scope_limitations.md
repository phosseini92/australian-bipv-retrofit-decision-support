# Scope and limitations

## Included in the locked Proceedings analysis

- Melbourne office reference archetype and eight design variants.
- Mounting-sensitive PV temperature and yield.
- Lifecycle energy, whole-life cost, service and replacement logic.
- PSCF-informed qualitative evidence representation.
- Pareto analysis, criterion-structure robustness, break-even thresholds, and
  bounded deterministic sensitivity.

## Deferred or excluded

- Calibrated project-specific building model and proprietary BIM.
- Full CFD cavity modelling.
- Probabilistic Monte Carlo analysis.
- Exhaustive Australian product database.
- Detailed embodied-LCA expansion beyond the defined scope.
- Whole-building cooling-load sensitivity without defensible thermal inputs.
- Site-specific external shading without site geometry.
- Separate transport-distance tariffs when the locked recycling cost already
  includes transport.

The direct and ventilated SAPM parameterisations are proxy bounds, not calibrated
façade-cavity models. Transferred failure rates, repair time, handled scope, and
some cost inputs remain explicitly provisional. Break-even values answer what
would have to be true; they are not claims that those threshold values currently
exist in the market.

The selected TMYx package is nominally labelled 2011–2025, but its own header
reports station data availability only for 2011–2015. Results therefore use the
exact locked file but must not be represented as a typical year derived from
fifteen complete years of measured station meteorology.
